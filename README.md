# Clinica Neveen — Website

Bilingual (English / Arabic) website for Dr. Neveen Dababneh's dermatology, aesthetics & laser clinic — 7th Circle, Amman.

## Pages
| File | Page |
|---|---|
| `index.html` | Home (hero, overview, about, services, before & after, CTA) |
| `services.html` | All treatments by category |
| `before-after.html` | Results gallery with comparison sliders (placeholders) |
| `booking.html` | Booking form → FormSubmit → clinic email |
| `working-hours.html` | Opening hours with live open/closed status |
| `faq.html` | Frequently asked questions |
| `contact.html` | WhatsApp, phones, email, map, social media |
| `privacy.html` | Privacy policy (linked from footer and form) |
| `thank-you.html` | Shown after a booking request is sent |

## Editing
The HTML pages are generated by `build.py` (all English + Arabic text lives there).
Edit the text in `build.py`, then run:

```bash
python3 build.py .
```

Styles: `assets/css/style.css` · Scripts: `assets/js/main.js` · Images: `assets/img/`

## Booking form (FormSubmit)
The form posts to `https://formsubmit.co/emadnivo@gmail.com`.
The **first** submission sends an activation email to that inbox — click **Activate** once.
After activation, FormSubmit gives a random alias; replace the email in `build.py` (`EMAIL` / form action) with it to hide the address from the page source.

## Before & After photos
Each slider has two panes (`.ba-before` / `.ba-after`). To add photos, put an `<img>` inside each pane, e.g.
`<div class="ba-pane ba-before"><img src="assets/img/ba/jawline-before.jpg" alt="..."></div>`.

## Publish on GitHub Pages
Settings → Pages → Deploy from branch → `main` / root.
